# Midterm 2 Practice Quiz

Interactive 225-question multiple-choice quiz covering Dr. Mollhoff's Week 4–6 lecture content: embryology, tissue types, histology, cell junctions, glands, membranes, the integumentary system, wound healing, homeostasis, and the cell cycle. Includes a separate 50-question slide-ID quiz keyed to Dr. Mollhoff's lecture micrographs and diagrams (Q1–2 link to verified histologyguide.com slides).

## Features

- **225 MCQs** in the main bank, plus **50 slide-ID questions** in a separate slide quiz mode (Q1–2 use verified histologyguide.com micrographs; Q3–50 are flashcards keyed to Dr. Mollhoff's lecture slides)
- Both modes share the same live category meters, retake-missed loop, and end-of-round weak-areas report
- **Live category meters** on the side panel as you take the quiz:
  - Colored fill = correct answers (out of total in that category)
  - Gray "ghost" fill behind = questions seen (correct + wrong)
  - Color shifts green → blue → amber → red based on accuracy
  - Mastery tier label (Untouched / Novice / Learning / Solid / Mastered)
- **Retake-missed loop:** after each round, retake only the questions you missed and keep looping until 100%
- **End-of-quiz weak-areas report** flagging any topic under 70%
- **Full review** of every missed question with your pick vs. the correct answer
- Sequential or shuffled order; optional instant feedback per question

## Run

Open `index.html` in any modern browser — no build step, no dependencies.

## Notes on the question set

Two answer-key items from the source material were corrected to match standard anatomy:
- **Q123** — Deeper layer of the dermis = **Reticular layer** (source said "Stratum basale", which is an epidermal layer).
- **Q124** — Reticular layer tissue = **Dense irregular CT** (source said "Dense regular", which is for tendons/ligaments).
